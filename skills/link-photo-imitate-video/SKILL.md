# 链接照片仿视频

用户给一条参考视频（链接或文件），或再加一组照片要求做成和参考视频同格式的成片时使用。不要猜链接，不要擅自省掉用户给的造型。

本技能分两段：先提取参考视频；若用户还要按照片复刻，再走后半段。只要下载、不要成片时，提取并交付后即可停止。

## 一、从链接提取参考视频

- 用户已经发来文件，或已在自己的浏览器、微信里另存好：直接用这个文件，不要再绕下载。用户能自己另存时，拿他保存好的文件比在云电脑上绕拦截更快。
- 只处理用户给的链接或亚马逊 ASIN。说「腾讯视频」时通常指视频号，先按视频号处理，拿不准再问一句。
- 只要下载时，交付副本放 `/workspace/your_files/`，原片留在各平台下载目录。还要复刻时，工作目录用 `/workspace/imitate-video/`（或当次专用目录），把校验过的副本放进去并命名为 `reference.mp4`。
- 每条视频交付或进入复刻前，用 ffprobe 验时长、分辨率和编码。
- 解析 JSON 等带 token 的临时文件用完就删。

### 视频号

- 只接受 `weixin.qq.com/sph` 的分享链接，其他链接解析不了。
- 先请用户在微信或自己的浏览器里另存视频后发过来。这比在云电脑上绕拦截更快。
- 若要自动解析：POST `https://v.mtotech.com/api/resolve`，body 为 `{"url": "分享链接"}`，返回 JSON 里有 `h264_url` 和 `h265_url`，不用登录。不要用 curl 直连 `finder.video.qq.com`，云电脑上一律空响应，不要反复重试。
- 直链里的 token 会在工具输出里被打码，不要把直链粘贴给浏览器任务。若要交给浏览器下载，把解析 JSON 存到 `/workspace/video-downloads/` 下的文件里，用文件授权方式读取，下完后删掉该文件。
- 2026-10-29 起，浏览器任务读不到解析文件、分享页也没有下载按钮的路已断，不要原样重跑那条旧路。旧工具若还在 `/workspace/sph-tool/`，登录会话过期时不要先花时间修它，优先请用户另存或去 GitHub 找替代方案。

### 抖音

- 用 GitHub 的 `lyf9528/douyin-dl`，装在 `/workspace/tools/douyin-dl/`，入口是 `.venv/bin/douyin-dl`，免登录，用匿名 ttwid。目录里没有就先克隆再装。
- 先跑 `info` 看元数据和清晰度，再跑 `get` 下载，`doctor` 用来验证免登录通道是否通。
- 跑之前设置 `NO_PROXY=localhost,127.0.0.1`。默认的 `NO_PROXY` 里带括号的 IPv6 会让 httpx 报 Invalid port；直连还会报 SSL 错，要走出口代理。
- 抖音会间歇性回反爬壳或超时，`info` 或 `get` 失败时多重试几次，不要一次失败就判死刑。
- 不要用 yt-dlp 的 Douyin 抽取器，它要登录 cookies。
- 下载物放 `/workspace/douyin-downloads/`，ffprobe 验过再拷到工作目录或 `/workspace/your_files/`。

### 亚马逊商品视频

- amazon.com 和 amazon.co.uk 对云电脑常只返回约 3.7KB 拦截页，换 UA 也没用，不要在上面浪费时间。
- 换 amazon.ca，同 ASIN 能拿到真实商品页。ASIN 从商品链接的 `/dp/` 后面取。
- curl 必须加 `--compressed`，不然拿到的是 gzip 乱码。
- 用这条从页面里找直链：`grep -oE 'https://m\.media-amazon\.com[^"\\]*productVideoOptimized\.mp4' page.html | sort -u`，直链直接 curl 下载，不用登录。
- 同一商品页可能挂多个视频，多为同品牌其他商品的交叉广告。下载后逐条看帧，确认哪条是本品视频再当参考或交付。
- 如果 .ca 也开始拦，换个 UA 或隔一会儿再试，不要硬刷。

### 其他链接或工具链不通

可先试通用下载器。不通就请用户另存后发过来，或去 GitHub 找现成方案。几分钟能通的路不要花一小时硬修。

### 只要提取、不要复刻时

用 ffprobe 核验后，把副本放到 `/workspace/your_files/`，作为附件交给用户，并短说时长和分辨率。到此结束，不要自动进入复刻。

## 二、用照片复刻成片

进入本段的前提：用户给了照片，并要求按参考视频做成同格式成片。参考视频按第一段拿到，并已放到工作目录的 `reference.mp4`。

### 1. 拆解参考视频

- 不要声称已经「看过」视频。把参考视频放在 `/workspace` 下，用 ffprobe 记下时长、分辨率、帧率、有无音轨、画幅（如 9:16、1:2）。
- 用 ffmpeg 按约 1fps 抽帧，再逐帧读图，整出镜序。若有视频分析工具且文件已在 `/workspace`，可用来核对外观；失败就只用抽帧，不要假装看过。
- 为每一镜记下：人物姿态、景别、站位、背景、道具或色卡或文字、转场方式（硬切、渐变、灰度变上色、转身、挥手等）、大约起止秒数。
- 参考若有配乐或原声，生成模型不会自动带上；成片出来后用 ffmpeg 把参考音轨混进去，并对齐或裁切时长。

### 2. 把照片对到各镜

- 按参考镜序给每张照片分镜。缺镜或多余造型要明说，得到确认前不要擅自省略。
- 同一人换装：每套衣服对应参考里的对应镜，不要把多套合成一个人。

### 3. 按参考构图做静帧

- 不要改用户的原图。人物扣图用 rembg（建议独立 venv），按参考画幅合成（常见 1080×2160 或 9:16）。
- 参考里的色卡、品牌字、排版，用脚本画进静帧。不要指望生成模型写出精确文字或品牌资产。
- 色卡、扇形等元素不要贴出画外；合成后目视检查裁切。
- 若用户有固定水印要求，加在静帧上（右下角实标 + 画面中央浅水印），不要靠生成模型去写。
- 导出高质量 JPEG，作为生成用帧。

### 4. 用静帧生成视频

- 只在用户明确要求做视频时调用生成视频工具。
- 用首帧、尾帧钉住两端；中间最多再钉 4 个关键帧，每个关键帧的时间戳须严格落在 0 与时长之间。整段最多可靠钉 6 张静帧。
- 时长限 1–15 秒，尽量贴近参考时长。超过 15 秒或超过 6 个关键造型，就分段生成，再用 ffmpeg 拼接。
- 提示词写清人物、动作、运镜、光线、转场，并与各关键秒对齐。人物与服装以静帧为准，不要改脸或改衣服。
- 中间变形容易发脏：每个关键造型必须钉在对应秒；提示词避免「慢慢融化成下一套衣服」，能切就切。
- 带尾帧、关键帧或参考图时，不要指定 1080p（工具会拒绝或降到 720p），这时用 720p。1080p 只适用于纯文生或单张图生、且没有尾帧、关键帧和参考图。画幅按参考选择。
- 生成可能要几分钟，一次请求等它跑完。

### 5. 核对与交付

- 用 ffprobe 验成片时长、分辨率、编码。再抽几帧对照参考和原照片，确认人物、服装、镜序都在，没有漏造型。
- 先把成片作为附件发出，再短说镜序和已知缺陷（如中间过渡发糊、分辨率低于参考、未纳入的造型）。
- 用户下不下来时，再按他指定的位置上传（如网盘），不要默认乱传。
